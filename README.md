# Студентарија.мк (Studentarija.mk)

**Студентарија.мк** е модерна веб платформа посветена на македонските студенти. Платформата служи како централен информатор за вести, настани, огласи за кариера и студентски поволности.

## 🚀 Главни Функционалности

- **Динамични Вести:** Најнови информации од студентскиот живот, стипендии и административни известувања.
- **Студентски Настани:** Интерактивен календар и листа на журки, работилници и спортски настани со можност за филтрирање по град.
- **Админ Портал:** Комплетен систем за управување со содржина (CMS) кој овозможува лесно додавање и уредување на вести, настани и страници.
- **Динамични Страници:** Можност за креирање на нови под-страници директно преку админ панелот.
- **Интуитивен Дизајн:** Модерен, брз и одговорен (responsive) кориснички интерфејс со акцент на UX.
- **Порака на денот:** Забавни и мотивациони пораки за студентите.

## 🛠 Технологии

- **Frontend:** [React.js](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Јазик:** [TypeScript](https://www.typescriptlang.org/)
- **Стилизација:** [Tailwind CSS](https://tailwindcss.com/)
- **Анимации:** [Motion](https://motion.dev/)
- **Backend & Database:** [Supabase](https://supabase.com/) (PostgreSQL + Auth + Storage)
- **Икони:** [Lucide React](https://lucide.dev/)

## 📁 Структура на Проектот

- `/src/pages`: Главни рути (Home, Admin, Posts, Events, и др.).
- `/src/components`: Реупотребливи компоненти и делови од интерфејсот.
- `/src/lib`: Конфигурација на Supabase и помошни алатки.
- `/src/types`: TypeScript дефиниции.

## ⚙️ Локално Подесување

1. **Инсталација на зависности:**
   ```bash
   npm install
   ```

2. **Стартување на развојна околина:**
   ```bash
   npm run dev
   ```

3. **Изградба на апликацијата (Production build):**
   ```bash
   npm run build
   ```

## 🔐 Сигурност

Апликацијата користи **Supabase Row Level Security (RLS)** за заштита на податоците.
- Јавните корисници имаат пристап само за читање.
- Само овластени лица со валидни крединцијали можат да пристапат до `/admin` за уредување на содржината.
